## Objetivo

Cuando el descubrimiento automático falla, una pantalla simple pide "Nombre del PC servidor o IP"
y permite reintentar la búsqueda.

## Pasos de ejecución

1. Modal de conexión (ver `docs/05-app.md`) con: mensaje de por qué se muestra, campo de texto,
   botones **Conectar** y **Buscar de nuevo**.
2. **Conectar** → `invoke('conectar_manual', { direccion })`; en error, mostrar el mensaje en
   español bajo el campo sin cerrar el modal.
3. **Buscar de nuevo** → `invoke('conectar')`.
4. Mientras espera: botones deshabilitados y texto "Buscando servidor…".
5. Enter en el campo = Conectar. Foco automático en el campo.

## Validaciones

- [ ] V1 — Sin API: la pantalla aparece sola al abrir la app.
- [ ] V2 — Escribir `localhost` con la API corriendo → conecta y muestra la grilla.
- [ ] V3 — Escribir `PC-QUE-NO-EXISTE` → mensaje "No se encontró el equipo…" y el modal sigue abierto.
