# T-3.5 — Manejo del error 409 con el mensaje correspondiente

| Campo | Valor |
|---|---|
| Fase | 3 — App Tauri |
| Cubre | RF-05 |
| Depende de | T-3.4 |
| Componente | app |
| Rama sugerida | `dev/fase-3-app` |
| Estado | pendiente |

## Objetivo

Si la API responde `409 bloque_ocupado`, el usuario ve exactamente **"Ese bloque acaba de ser
tomado"** y la grilla se actualiza mostrando quién lo tomó.

## Pasos de ejecución

1. `ErrorCliente::Api(ErrorRespuesta)` se serializa al frontend como `{ codigo, mensaje }`.
2. En el modal de reserva, si `codigo === 'bloque_ocupado'`: cerrar el modal, mostrar aviso
   (toast/banner visible 6 s) con el mensaje y refrescar la grilla.

## Validaciones

- [ ] V1 — Reservar por curl el bloque mientras el modal está abierto, luego presionar Reservar →
      aparece "Ese bloque acaba de ser tomado" y la celda muestra la reserva del otro.
- [ ] V2 — Prueba de aceptación 2 (dos PCs a la vez) reproducida localmente con dos ventanas.
