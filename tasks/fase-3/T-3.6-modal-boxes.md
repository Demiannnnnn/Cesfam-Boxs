# T-3.6 — Modal de configuración de boxes

| Campo | Valor |

| Estado | pendiente |

## Objetivo

Desde el botón "⚙ Boxes": agregar, renombrar y activar/desactivar boxes.

## Pasos de ejecución

1. Comandos `listar_boxes(incluir_inactivos)`, `crear_box(nombre)`, `actualizar_box(id, cambios)`.
2. Modal con lista (todos, incluidos inactivos): campo de nombre + botón Guardar por fila, casilla
   "Activo"; abajo campo "Nuevo box" + Agregar.
3. Errores (`nombre_duplicado`, vacío) bajo la fila correspondiente.
4. Al cerrar, refrescar la grilla.
5. Desactivar un box con reservas futuras: avisar "Este box tiene reservas futuras; seguirán
   guardadas pero no se verán en la grilla" y pedir confirmación.

## Validaciones

- [ ] V1 — Agregar "Box 9" → aparece como última columna.
- [ ] V2 — Renombrar → la columna cambia de nombre; nombre duplicado → mensaje.
- [ ] V3 — Desactivar → la columna desaparece; reactivar → vuelve con sus reservas.
