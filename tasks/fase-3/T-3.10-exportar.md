# T-3.10 — Exportar a Excel o CSV (opcional)

| Campo | Valor |
|---|---|
| Fase | 3 — App Tauri |
| Cubre | RF-12 |
| Depende de | T-3.3, T-2.4 (rango) |
| Componente | app/src-tauri (`exportar.rs`) |
| Rama sugerida | `dev/fase-3-exportar` |
| Estado | pendiente |

## Objetivo

Exportar las reservas de un rango a CSV que Excel abre correctamente en español.

## Pasos de ejecución

1. `exportar.rs`: `fn generar_csv(reservas, boxes) -> String` (pura, testeable): BOM UTF-8,
   separador `;`, encabezado `Fecha;Hora;Box;Funcionario;Motivo`, fecha `DD-MM-AAAA`, escapar
   comillas y `;` según RFC 4180. Prefijar con `'` celdas que empiecen con `=`, `+`, `-`, `@`
   (evita inyección de fórmulas en Excel).
2. Comando `exportar_csv(desde, hasta, ruta)`; la ruta se elige con el diálogo de guardar
   (`tauri-plugin-dialog`).
3. Botón "Exportar" + mini formulario de rango (por defecto: mes actual).

## Validaciones

- [ ] V1 — Test: motivo con `;` y comillas queda bien escapado.
- [ ] V2 — Test: funcionario `=HYPERLINK(...)` se exporta como `'=HYPERLINK(...)`.
- [ ] V3 — El archivo abre en Excel (es-CL) con columnas separadas y tildes correctas.
