# T-3.1 — Lógica de conexión: guardada → /health → broadcast → manual

| Campo | Valor |

| Estado | pendiente |

## Objetivo

Comando `conectar()` que en menos de 5 s devuelve la dirección del servidor o indica que hay que
pedirla manualmente, y guarda la última dirección válida.

## Contexto

- Flujo: `docs/03-arquitectura.md` § Descubrir el servidor.
- ADR-005, ADR-007.

## Pasos de ejecución

1. `config_local.rs`: `ConfigLocal { servidor: Option<String>, equipo_servidor: Option<String>, ultimo_funcionario: Option<String> }`,
   `cargar(ruta)` (archivo inexistente o corrupto → valores por defecto + `warn`),
   `guardar(ruta)` atómico (escribir `.tmp` y `rename`).
2. `cliente_api.rs`: `ClienteApi { base: String, http: reqwest::Client }` con timeout de
   conexión 1,5 s y total 5 s; métodos `salud`, `boxes`, `reservas`, `crear_reserva`, … que
   devuelven `Result<T, ErrorCliente>` con `ErrorCliente::{SinConexion, NombreNoResuelto, Api(ErrorRespuesta), Inesperado}`.
3. `conexion.rs` — **cadena de responsabilidad**:
   ```rust
   #[async_trait]? / fn async en trait (Rust ≥1.75)
   trait Estrategia { async fn intentar(&self) -> Option<Servidor>; fn nombre(&self) -> &str; }
   struct DireccionGuardada(String);
   struct Broadcast { puerto: u16, espera: Duration, intentos: u8 }
   async fn descubrir(estrategias: &[&dyn …]) -> Option<Servidor>
   ```
   `Servidor { direccion: "host:puerto", equipo: String }` — siempre confirmado con `/health`.
4. Broadcast: `UdpSocket::bind("0.0.0.0:0")`, `set_broadcast(true)`, enviar a
   `255.255.255.255:8001`, esperar 1,5 s, 2 intentos; la primera respuesta válida gana.
5. Comandos Tauri: `conectar() -> ResultadoConexion { Conectado{servidor, equipo} | RequiereManual{mensaje} }`
   y `conectar_manual(direccion)`; normalizar entrada (`PC-SOME` → `PC-SOME:8000`; quitar `http://`).
6. Guardar en `ConfigLocal` cuando se conecta a una dirección distinta de la guardada.

## Patrones y buenas prácticas

- **Cadena de responsabilidad / estrategia**: agregar un método nuevo (p. ej. mDNS) = agregar
  una estrategia, sin tocar las demás.
- Timeouts explícitos en toda operación de red; nunca esperar indefinidamente.
- Lógica testeable sin red: `normalizar_direccion` y la cadena con estrategias falsas.

## Validaciones

- [ ] V1 — Tests: `normalizar_direccion("http://PC-SOME/")` → `"PC-SOME:8000"`; `"10.0.0.5:9000"` se respeta.
- [ ] V2 — Test: cadena con [falla, éxito] devuelve el éxito; con [falla, falla] → `None`.
- [ ] V3 — Test: `ConfigLocal::cargar` con JSON corrupto devuelve valores por defecto.
- [ ] V4 — Manual: API local corriendo + `cliente.json` con IP incorrecta → la app conecta por broadcast en < 5 s
      y `cliente.json` queda con la dirección nueva.
- [ ] V5 — Manual: sin API → la app pide ingreso manual en < 5 s.
