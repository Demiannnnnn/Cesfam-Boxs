## Objetivo

Pantalla principal: tabla con boxes activos en columnas y 24 bloques en filas, con botones
Anterior / Hoy / Siguiente y un `<input type="date">`.

## Pasos de ejecución

1. `estado.ts`: `{ fecha: string, boxes: BoxAtencion[], reservas: Reserva[], conexion: EstadoConexion }`
   y funciones puras para cambiar día (`sumarDias(fecha, n)`), sin depender del DOM.
2. `horario.ts`: `etiquetaBloque(n)`, `bloqueActual(ahora)`, constantes iguales a `shared::horario`
   (o obtenidas con un comando `horario()` desde Rust → **preferido**, fuente única).
3. `grilla.ts`: `renderizarGrilla(contenedor, estado, acciones)` usando `<table>`, `<th scope>`,
   `<button>` por celda; índice `Map<"boxId-bloque", Reserva>` para O(1).
4. Encabezado con fecha larga en español (`toLocaleDateString('es-CL', {weekday:'long', …})`).
5. Resaltar fila del bloque actual si la fecha es hoy; atenuar bloques pasados.
6. Encabezado de tabla fijo (`position: sticky`) para scroll vertical.

## Patrones y buenas prácticas

- **Render desde estado**: cada cambio → `renderizar()`. Sin estado escondido en el DOM.
- `textContent`, nunca `innerHTML` con datos.
- Fechas como string `AAAA-MM-DD` en todo el frontend; evitar `new Date("2026-10-01")` (UTC) → usar
  constructor local `new Date(a, m-1, d)`.

## Validaciones

- [ ] V1 — Con 4 boxes activos y 1 inactivo, la grilla muestra 4 columnas y 24 filas (08:00…19:30).
- [ ] V2 — Anterior/Siguiente cambian un día; Hoy vuelve a hoy; el selector salta a la fecha elegida.
- [ ] V3 — Navegar cruzando fin de mes/año funciona (31-12 → 01-01).
- [ ] V4 — Una reserva creada por curl aparece en la celda correcta.
- [ ] V5 — Un funcionario llamado `<b>x</b>` se muestra literal, sin negrita.
