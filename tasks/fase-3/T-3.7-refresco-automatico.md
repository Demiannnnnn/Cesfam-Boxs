# T-3.7 — Refresco automático cada 15 a 30 segundos

| Campo | Valor |
|---|---|
| Fase | 3 — App Tauri |
| Cubre | RF-07 |
| Depende de | T-3.3 |
| Componente | app/src (`main.ts`) |
| Rama sugerida | `dev/fase-3-app` |
| Estado | pendiente |

## Objetivo

La grilla se actualiza sola cada 20 s sin que el usuario haga nada.

## Pasos de ejecución

1. `const INTERVALO_REFRESCO_MS = 20_000` en un solo lugar.
2. Usar `setTimeout` encadenado (no `setInterval`) para que nunca se solapen dos refrescos lentos.
3. Pausar mientras hay un modal abierto; refrescar inmediatamente al cerrarlo.
4. Si el refresco falla → estado "sin conexión" (T-3.8) y en el siguiente ciclo reintentar
   `conectar()` (redescubre si cambió la IP).
5. Refrescar también al volver la ventana a primer plano (`visibilitychange`).

## Validaciones

- [ ] V1 — Crear una reserva por curl; la app la muestra en ≤ 20 s sin interacción.
- [ ] V2 — Con un modal abierto la grilla no cambia; al cerrarlo se actualiza.
- [ ] V3 — Detener la API 1 min y reiniciarla: la app vuelve a "Conectado" sola.
