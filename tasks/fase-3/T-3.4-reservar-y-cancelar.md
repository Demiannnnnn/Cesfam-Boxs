# T-3.4 — Formulario para reservar y vista de detalle con cancelación

| Campo | Valor |
|---|---|
| Fase | 3 — App Tauri |
| Cubre | RF-03, RF-04, RNF-11 |
| Depende de | T-3.3 |
| Componente | app/src (`componentes/modales.ts`), app/src-tauri (`comandos.rs`) |
| Rama sugerida | `dev/fase-3-app` |
| Estado | pendiente |

## Objetivo

Clic en celda libre → modal de reserva; clic en celda ocupada → detalle con "Cancelar reserva".

## Pasos de ejecución

1. Comandos Tauri `crear_reserva(nueva)`, `cancelar_reserva(id)` en `comandos.rs`.
2. Modal de reserva con `<dialog>`: box, fecha, hora (solo lectura); nombre (required, maxlength 80,
   prellenado con `ultimo_funcionario`); motivo (maxlength 200); botón Reservar deshabilitado
   mientras se envía (evita doble clic).
3. Éxito → cerrar, guardar `ultimo_funcionario`, refrescar grilla.
4. Detalle: datos + "Cancelar reserva" → `confirm` propio (no `window.confirm`) "¿Cancelar la reserva
   de {nombre} a las {hora}?" → `cancelar_reserva` → refrescar.
5. Escape cierra modales.

## Validaciones

- [ ] V1 — Reservar con nombre → aparece en la grilla.
- [ ] V2 — Reservar sin nombre → el formulario no se envía y muestra el aviso.
- [ ] V3 — Cancelar desde el detalle → la celda queda libre.
- [ ] V4 — Doble clic rápido en Reservar → una sola petición (verificar en `api.log`).
- [ ] V5 — Cancelar algo ya cancelado desde otro PC → "Esa reserva ya había sido cancelada." y la grilla se refresca.
