## Objetivo

README en la raíz que permita a alguien nuevo compilar y ejecutar API y App, más el andamiaje
de documentación (`AGENTS.md`, `docs/`, `.ai-context/`, `tasks/`).

## Pasos de ejecución

1. Redactar `README.md`: propósito, alcance, arquitectura breve, estructura, requisitos de
   desarrollo, comandos de compilación/ejecución/pruebas, flujo de ramas, fases.
2. Crear `AGENTS.md`, `docs/`, `.ai-context/`, `tasks/`.
3. Crear ramas `develop` y `dev/documentacion-base`.

## Validaciones

- [x] V1 — README contiene comandos de compilación de API y App y de pruebas.
- [x] V2 — Todos los enlaces relativos del README apuntan a archivos existentes.
- [ ] V3 — Una persona que no participó sigue el README y levanta la API en < 15 min
      (verificar cuando exista el código).
