# T-2.7 — Agregar CorsLayer permisivo

| Campo | Valor |
|---|---|
| Fase | 2 — API |
| Cubre | RNF-07 |
| Depende de | T-2.6 |
| Componente | api (`http/mod.rs`) |
| Rama sugerida | `dev/fase-2-api` |
| Estado | pendiente |

## Objetivo

Permitir peticiones desde la webview de Tauri (`tauri://localhost`, `http://tauri.localhost`)
y desde un navegador de diagnóstico.

## Pasos de ejecución

1. `tower_http::cors::CorsLayer::permissive()` aplicada al router completo.
2. Comentar en el código por qué es aceptable (LAN, sin auth, datos no sensibles; ADR-002/007).

## Validaciones

- [ ] V1 — `curl -i -X OPTIONS localhost:8000/reservas -H 'Origin: tauri://localhost' -H 'Access-Control-Request-Method: POST'`
      incluye `access-control-allow-origin`.
- [ ] V2 — Test de integración que verifica el header en un `GET /health` con `Origin`.
