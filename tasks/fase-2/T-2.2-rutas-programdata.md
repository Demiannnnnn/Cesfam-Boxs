# T-2.2 — Resolver rutas en `C:\ProgramData\GestionBox\` y crear las carpetas

| Campo | Valor |
|---|---|
| Fase | 2 — API |
| Cubre | RNF-03, RNF-04 |
| Depende de | T-1.1 |
| Componente | api (`config.rs`) |
| Rama sugerida | `dev/fase-2-api` |
| Estado | completada (2026-10-01, rama `dev/fase-1-2-api`) |

## Objetivo

Un struct `Config` resuelto una vez al arrancar con rutas **absolutas** a base, respaldos y log,
y puertos HTTP/UDP, creando las carpetas si no existen.

## Contexto

- ADR-013 (override `GESTIONBOX_DATA_DIR`).
- Un servicio NSSM arranca con directorio de trabajo `C:\Windows\System32`: rutas relativas
  romperían todo. Por eso RNF-04 exige absolutas.

## Pasos de ejecución

1. `api/src/config.rs`:
   ```rust
   pub struct Config {
       pub carpeta_datos: PathBuf,
       pub ruta_db: PathBuf,
       pub carpeta_respaldos: PathBuf,
       pub ruta_log: PathBuf,
       pub puerto_http: u16,
       pub puerto_udp: u16,
   }
   impl Config {
       pub fn desde_entorno() -> Result<Self, ErrorConfig>;
       pub fn con_carpeta(carpeta: PathBuf) -> Self; // tests
       pub fn crear_carpetas(&self) -> io::Result<()>;
   }
   ```
2. Carpeta por defecto: `#[cfg(windows)]` → `%ProgramData%\GestionBox` (variable `ProgramData`,
   con respaldo literal `C:\ProgramData`); otros SO → `./datos-dev` convertido a absoluto con
   `std::path::absolute`.
3. Puertos desde `GESTIONBOX_HTTP_PORT` / `GESTIONBOX_UDP_PORT` con defecto 8000/8001;
   valor inválido → `ErrorConfig` con mensaje en español.

## Patrones y buenas prácticas

- **Configuración centralizada e inmutable**: se calcula en `main` y se pasa por referencia;
  ningún módulo lee variables de entorno por su cuenta.
- Funciones puras testeables: separar `resolver(env: impl Fn(&str) -> Option<String>)` de la
  lectura real del entorno para testear sin modificar variables globales.

## Validaciones

- [x] V1 — Test: con `GESTIONBOX_DATA_DIR=/tmp/x` todas las rutas empiezan con `/tmp/x` y son absolutas.
- [x] V2 — Test: puerto `"abc"` produce error con mensaje en español.
- [x] V3 — Ejecutar la API desde otro directorio (`cd /; GESTIONBOX_DATA_DIR=… gestion-box-api`)
