## Objetivo

Endpoint liviano que la app usa para saber si el servidor está vivo y cómo se llama el equipo.

## Pasos de ejecución

1. `InfoServidor { version: env!("CARGO_PKG_VERSION"), equipo: String }` en `AppState`.
2. Nombre de equipo: variable `COMPUTERNAME` (Windows) o `HOSTNAME`; si no existe,
   crate `hostname` o `"servidor"`.
3. Handler devuelve `EstadoSalud { estado: "ok", version, equipo }`.
4. Además hacer `SELECT 1` en la base: si falla → 500 (la app lo mostrará como error del servidor).

## Validaciones

- [x] V1 — `curl -s localhost:8000/health` → `{"estado":"ok","version":"0.1.0","equipo":"…"}`.
- [x] V2 — Tiempo de respuesta < 50 ms en local (`curl -w '%{time_total}'`).
- [x] V3 — Test de integración del endpoint.
