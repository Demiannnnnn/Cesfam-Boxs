## Objetivo

Cobertura de tests de integración de todos los endpoints y un script de humo reproducible.

## Pasos de ejecución

1. `api/tests/` con un archivo por recurso y un módulo `comun` con `estado_de_prueba()`.
2. `api/scripts/humo.sh` (bash + curl) que levanta la API en una carpeta temporal, ejecuta el
   recorrido completo (health → crear box → reservar → 409 → listar → cancelar → 404) y verifica
   códigos HTTP. Sale con código ≠ 0 si algo falla.
3. Equivalente `api/scripts/humo.ps1` para Windows (opcional, recomendado para T-5.1).

## Validaciones

- [x] V1 — `cargo test -p gestion-box-api` pasa; cada endpoint tiene al menos un caso feliz y uno de error.
- [x] V2 — `bash api/scripts/humo.sh` termina con "Prueba de humo OK".
- [x] V3 — Las validaciones de T-2.1 a T-2.10 están todas marcadas.
