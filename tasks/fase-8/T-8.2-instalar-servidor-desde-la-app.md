| Campo | Valor |
|---|---|
| Fase | 8 — Varios equipos: modos, copia diaria y servidor de reemplazo |
| Cubre | RF-16, RNF-12, RNF-14 |
| Depende de | T-8.1, T-4.2, T-4.4 |
| Componente | app, instalador |
| Rama sugerida | `dev/fase-8-multiequipo` |
| Estado | implementada — validación manual pendiente |

## Objetivo

Elegir "Este equipo es el servidor" en el asistente instala la API como servicio de Windows, que
arranca sola al encender el PC, sin que nadie abra `instalar.bat` a mano.

## Contexto

- ADR-018 (NSSM), ADR-020. `instalador/instalar.bat` (T-4.2) ya crea carpetas, servicio NSSM con
  arranque automático y reglas de firewall. `app/src-tauri/tauri.conf.json` (T-4.4).
- Windows es la prioridad. En otros sistemas la opción muestra "Solo disponible en Windows".

## Pasos de ejecución

1. `tauri.conf.json`: `bundle.resources` incluye `gestion-box-api.exe`, `nssm.exe`, `instalar.bat`
   y `desinstalar.bat` en una carpeta `servidor/`. Documentar en T-4.4 y `docs/06-instalacion.md` que
   antes de `tauri build` hay que compilar la API en release y copiar NSSM 2.24-101 a esa carpeta
   (no se versionan binarios).
2. `instalar.bat`: agregar, tras el firewall, `powercfg /change standby-timeout-ac 0` y
   `powercfg /change hibernate-timeout-ac 0` (RNF-14), con mensaje de error propio si fallan. Aceptar
   un argumento opcional `/respaldo "<ruta>"`: si viene y no existe aún la base, copia ese archivo
   como `%ProgramData%\GestionBox\gestion-box.db` antes de iniciar el servicio (lo usa T-8.5). Sin
   argumento, el comportamiento actual no cambia.
3. Comando Tauri `instalar_servidor(respaldo: Option<String>)`: solo en Windows (`cfg`), lanza el
   `instalar.bat` de los recursos con elevación (PowerShell `Start-Process -Verb RunAs -Wait`), espera
   su código de salida y luego consulta `http://127.0.0.1:8000/health` hasta 20 s. Devuelve éxito o
   un error en español con qué revisar (incluido "Se canceló el permiso de administrador").
4. En el asistente, `Servidor` llama al comando y muestra "Instalando el servidor…"; al terminar
   guarda modo `servidor`, guarda `127.0.0.1:8000` como dirección y abre la grilla.
5. El equipo servidor también reserva: su app se comporta como `escritura`, sin copia diaria.

## Patrones y buenas prácticas

- Reutilizar `instalar.bat`; no duplicar su lógica en Rust.
- Rutas con espacios: todas las rutas entre comillas en la línea de PowerShell.

## Estado de validación (2026-11-06)

Implementada. `bundle.resources` = `servidor/*` sobre `app/src-tauri/servidor/` (solo `LEEME.txt`
versionado). `instalar.bat` acepta `/sinpausa` (lo usa la app) y `/respaldo "<ruta>"`, usa
`shift /1` para no perder `%~dp0` y ajusta la energía con `powercfg` (fallo = advertencia). La app
eleva con PowerShell `Start-Process -Verb RunAs` pasando la línea de `cmd` por variable de entorno.
V1: ramas del `.bat` probadas con el `cmd` de Wine y órdenes simuladas, incluida la ejecución desde
otra carpeta (no es Windows real). 157 tests y `npm run check` pasan.
**V2 no se pudo ejecutar:** el target `x86_64-pc-windows-msvc` no está instalado en este equipo
(Rust de Arch sin rustup), así que el código `cfg(windows)` no se compiló; se revisó a mano.
Faltan V2 a V4 en Windows.
