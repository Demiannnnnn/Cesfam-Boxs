# T-8.1 — Modo del equipo y asistente de primer inicio

| Campo | Valor |
|---|---|
| Fase | 8 — Varios equipos: modos, copia diaria y servidor de reemplazo |
| Cubre | RF-16, RF-17 |
| Depende de | fase 7 |
| Componente | app |
| Rama sugerida | `dev/fase-8-multiequipo` |
| Estado | implementada — validación manual pendiente |

## Objetivo

La app sabe si el equipo es `servidor`, `escritura` o `lectura`, lo pregunta una sola vez al
primer inicio, y en `lectura` no muestra nada que modifique datos.

## Contexto

- ADR-020. `app/src-tauri/src/config_local.rs` (`cliente.json`), `app/src/estado.ts`, `textos.ts`.
- La API no cambia en esta tarea: el modo es solo de la app.

## Pasos de ejecución

1. `config_local.rs`: agregar `modo: Option<ModoEquipo>` con `enum ModoEquipo { Servidor,
   Escritura, Lectura }` serializado en minúsculas. Archivos viejos sin el campo cargan `None`.
   Tests: ida y vuelta de cada modo y lectura de un `cliente.json` antiguo sin `modo`.
2. Comandos Tauri `modo_equipo() -> Option<ModoEquipo>` y `elegir_modo(modo)`. `elegir_modo` solo
   funciona si el modo es `None` (primer inicio); si ya hay modo responde error. El cambio posterior
   es de T-8.5.
3. Asistente (`app/src/componentes/asistente.ts`): si `modo_equipo()` es `None`, antes de la grilla
   se muestra una pantalla con tres botones grandes y una línea cada uno:
   - **Este equipo es el servidor**: "Guarda los datos. Debe quedar siempre encendido."
   - **Equipo para reservar**: "Reserva y cancela. Guarda una copia diaria de los datos."
   - **Solo consulta**: "Ve la grilla, no puede reservar."
   Elegir `Servidor` llama a T-8.2 (mientras T-8.2 no exista, guarda el modo y muestra "Falta
   instalar el servidor"). Los otros dos guardan el modo y siguen a la conexión normal (RF-09).
4. Modo `lectura`: ocultar (no solo deshabilitar) reservar desde celdas y arrastre, cancelar,
   configuración de boxes, funcionarios y etiquetas. Se mantienen grilla, semana, búsqueda y
   exportar. Clic en una reserva muestra el detalle sin botón de cancelar. Clic en celda libre no
   hace nada. Una sola función `puedeEscribir()` en `estado.ts` decide todo.
5. Un texto discreto en la barra superior indica "Solo consulta" en modo lectura.
6. Textos en `textos.ts`, en español.

## Patrones y buenas prácticas

- Un único punto de decisión (`puedeEscribir()`); nada de comprobaciones repartidas.
- No agregar autenticación ni cambios en la API (ADR-020).

## Validaciones

- [ ] V3 — En `lectura` no aparece ningún control que cree, cambie o borre datos (revisar a mano

- [x] V4 — `npm run check` y los comandos de calidad de `tasks/README.md` pasan.

## Estado de validación (2026-11-06)

Implementada. V1 y V4 pasan en Linux (140 tests en el workspace, `npm run check`). Revisión del
código: toda llamada que crea, cambia o borra datos queda detrás de `puedeEscribir()`; en lectura
las celdas libres se dibujan como `<span>` sin acción y los botones de configuración y cancelar no
se muestran. Mientras T-8.2 no exista, elegir `Servidor` muestra "Falta instalar el servidor".
Faltan V2 y V3: requieren abrir la app con interfaz gráfica.
