## Objetivo

Asegurar que el broadcast UDP (`255.255.255.255:8001`) llega del cliente al servidor.
El broadcast no cruza routers ni VLANs distintas.

## Pasos de ejecución

1. En cada PC que usará la app: `ipconfig` → anotar IPv4 y máscara.
2. Calcular la red (IP AND máscara). Todas deben coincidir.
3. Si hay Wi-Fi y cable, comprobar que ambos estén en la misma red (a veces el Wi-Fi es otra VLAN).
4. Si algún PC está en otra subred: documentarlo; ese PC deberá usar el nombre o la IP
   (la conexión HTTP sí cruza routers, solo el descubrimiento no).

## Validaciones

- [ ] V1 — Tabla PC → IP/máscara/red registrada en *Notas*.
- [ ] V2 — Excepciones (otra subred) identificadas con su plan alternativo.
