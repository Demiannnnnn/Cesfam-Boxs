# T-0.3 — Identificar el PC servidor y anotar su nombre de equipo

| Campo | Valor |
|---|---|
| Fase | 0 — Validación en terreno |
| Cubre | RNF-08 |
| Depende de | — |
| Componente | terreno |
| Estado | bloqueada (requiere visita al CESFAM) |

## Objetivo

Elegir el PC que será servidor y registrar su nombre de equipo, IP actual, versión de
Windows y quién lo usa.

## Pasos de ejecución

1. Elegir un PC que: esté encendido en todo el horario de atención, tenga Windows 10/11,
   esté conectado **por cable** de preferencia y no sea un portátil que se lleva a casa.
2. En ese PC abrir `cmd` y ejecutar:
   ```bat
   hostname
   ipconfig /all
   winver
   ```
3. Registrar en *Notas*: nombre de equipo, IP, máscara, puerta de enlace, si la IP es DHCP,
   versión/compilación de Windows, usuario habitual.
4. Verificar que tenga al menos 500 MB libres en `C:`.
5. Revisar opciones de energía: que **no** entre en suspensión con el equipo enchufado
   (`powercfg /change standby-timeout-ac 0`, con permiso de TI).

## Validaciones

- [ ] V1 — Nombre de equipo, IP y versión de Windows registrados.
- [ ] V2 — Suspensión automática desactivada (o acordado con TI).
- [ ] V3 — Espacio libre ≥ 500 MB.
