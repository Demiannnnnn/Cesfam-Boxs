# T-0.4 — Probar `ping <nombre-pc>` desde otro equipo

| Campo | Valor |
|---|---|
| Fase | 0 — Validación en terreno |
| Cubre | RF-09 |
| Depende de | T-0.3 |
| Componente | terreno |
| Estado | bloqueada (requiere visita al CESFAM) |

## Objetivo

Saber si la red resuelve el nombre del PC servidor. Si funciona, la app puede guardar el
nombre (no la IP) y sobrevivir a cambios de IP sin broadcast.

## Pasos de ejecución

1. Desde al menos dos PCs cliente: `ping -n 4 <NOMBRE-SERVIDOR>`.
2. Registrar si responde y qué IP muestra.
3. Si no resuelve, probar `ping <NOMBRE-SERVIDOR>.local` y `nbtstat -a <NOMBRE-SERVIDOR>`.
4. Si el firewall bloquea ICMP pero el nombre resuelve (muestra IP y "tiempo agotado"), eso
   también sirve: lo importante es la **resolución de nombre**.

## Validaciones

- [ ] V1 — Resultado registrado por PC cliente: resuelve sí/no, IP mostrada.
- [ ] V2 — Decisión anotada: la app guardará `nombre:8000` o `ip:8000` por defecto.
