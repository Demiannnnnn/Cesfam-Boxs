# T-0.6 — Pedir a TI una reserva DHCP para el PC servidor (opcional)

| Campo | Valor |
|---|---|
| Fase | 0 — Validación en terreno |
| Cubre | RNF-08 |
| Depende de | T-0.3 |
| Componente | terreno |
| Estado | bloqueada (requiere a TI del CESFAM/DSM) |

## Objetivo

Que la IP del servidor no cambie. Es una capa extra: la app igual soporta cambios de IP.

## Pasos de ejecución

1. Enviar a TI la MAC del servidor (`ipconfig /all` → "Dirección física") y la IP deseada.
2. Pedir confirmación por escrito (correo) y registrarla en *Notas*.
3. Si TI no puede, no bloquea el proyecto: anotar "sin reserva DHCP" y confiar en nombre + broadcast.

## Validaciones

- [ ] V1 — Solicitud enviada y respuesta registrada (aprobada o rechazada).
- [ ] V2 — Si aprobada: tras reiniciar el servidor, `ipconfig` muestra la IP reservada.
