## Objetivo

Confirmar que todos los PCs tienen Windows 10 u 11 de 64 bits y WebView2 (requerido por Tauri).

## Pasos de ejecución

1. En cada PC: `winver` y `systeminfo | findstr /B /C:"Tipo de sistema"`.
2. Comprobar WebView2: Configuración → Aplicaciones → buscar "WebView2 Runtime".
   (Windows 11 lo trae; en Windows 10 el instalador `.msi` de Tauri lo descarga o se
   incluye el *bootstrapper* offline — ver T-4.4.)
3. Registrar si los PCs tienen salida a internet (define si el instalador puede descargar WebView2).

## Validaciones

- [ ] V1 — Tabla PC → versión, arquitectura, WebView2 sí/no, internet sí/no.
- [ ] V2 — Ningún PC con Windows 7/8 o 32 bits (si hay, escalar al responsable).
