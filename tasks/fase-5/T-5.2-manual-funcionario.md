# T-5.2 — Escribir el manual de una página para funcionarios

| Campo | Valor |
|---|---|
| Fase | 5 — Pruebas y entrega |
| Cubre | RNF-11 |
| Depende de | T-3.9 |
| Componente | docs (`07-manual-funcionario.md`) |
| Rama sugerida | `dev/fase-5-documentacion` |
| Estado | pendiente (borrador en `docs/07-manual-funcionario.md`) |

## Objetivo

Manual imprimible en **una** hoja: reservar, cancelar, cambiar de día, qué hacer si no conecta.

## Pasos de ejecución

1. Revisar el borrador contra la app real; agregar 2–3 capturas recortadas.
2. Exportar a PDF (A4, una página).
3. Validar con un funcionario que no participó.

## Validaciones

- [ ] V1 — Cabe en una hoja A4.
- [ ] V2 — Los nombres de botones coinciden exactamente con la app.
- [ ] V3 — Un funcionario lo lee y entiende sin preguntas.
