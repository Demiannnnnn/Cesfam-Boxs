# T-4.2 — Escribir instalar.bat

| Campo | Valor |
|---|---|
| Fase | 4 — Instalación |
| Cubre | RNF-01, RNF-03, RNF-12 |
| Depende de | T-4.1 |
| Componente | instalador |
| Rama sugerida | `dev/fase-4-instalacion` |
| Estado | pendiente |

## Objetivo

Un único `instalar.bat`, ejecutado como administrador, deja el servidor funcionando y
arrancando solo con Windows.

## Pasos de ejecución

1. Verificar privilegios (`net session >nul 2>&1 || (echo Ejecuta como administrador & pause & exit /b 1)`).
2. `chcp 65001` para tildes; `setlocal`; `cd /d "%~dp0"`.
3. Crear `C:\ProgramData\GestionBox\` y `backups\`.
4. Si el servicio existe: `nssm stop` (actualización) antes de copiar.
5. Copiar `gestion-box-api.exe` y `nssm.exe`.
6. Registrar con NSSM (idempotente: `nssm status` para decidir `install` o solo `set`):
   ```bat
   nssm install GestionBoxAPI "C:\ProgramData\GestionBox\gestion-box-api.exe"
   nssm set GestionBoxAPI AppDirectory "C:\ProgramData\GestionBox"
   nssm set GestionBoxAPI DisplayName "Gestión de Boxes CESFAM - API"
   nssm set GestionBoxAPI Start SERVICE_AUTO_START
   nssm set GestionBoxAPI AppExit Default Restart
   nssm set GestionBoxAPI AppRestartDelay 5000
   nssm set GestionBoxAPI AppStdout "C:\ProgramData\GestionBox\servicio.log"
   nssm set GestionBoxAPI AppStderr "C:\ProgramData\GestionBox\servicio.log"
   nssm set GestionBoxAPI AppRotateFiles 1
   nssm set GestionBoxAPI AppRotateBytes 1048576
   ```
7. Firewall (borrar y recrear para idempotencia):
   ```bat
   netsh advfirewall firewall delete rule name="GestionBox HTTP" >nul 2>&1
   netsh advfirewall firewall add rule name="GestionBox HTTP" dir=in action=allow protocol=TCP localport=8000 profile=private,domain
   netsh advfirewall firewall add rule name="GestionBox UDP"  dir=in action=allow protocol=UDP localport=8001 profile=private,domain
   ```
8. `nssm start GestionBoxAPI`; esperar y verificar con
   `powershell -NoProfile -Command "(Invoke-WebRequest -UseBasicParsing http://localhost:8000/health).StatusCode"`.
9. Mensaje final "Instalación completada" o instrucciones de qué revisar; `pause`.
10. Si existe `boxes-iniciales.txt` y no hay boxes, crearlos vía `POST /boxes`.

## Patrones y buenas prácticas

- **Idempotencia**: ejecutar el script dos veces = mismo resultado (sirve también para actualizar).
- Mensajes en español en cada paso; `exit /b` con código ≠ 0 ante fallo.
- Si la red está marcada como "Pública", advertir (el firewall no abrirá en perfil público).

## Validaciones

- [ ] V1 — En una VM Windows limpia: ejecutar como admin → "Instalación completada" y `/health` responde.
- [ ] V2 — Ejecutar de nuevo → termina bien sin duplicar servicio ni reglas (`netsh … show rule name=all | findstr GestionBox`).
- [ ] V3 — Reiniciar sin iniciar sesión → desde otra máquina `/health` responde (prueba de aceptación 1).
- [ ] V4 — Matar el proceso → NSSM lo reinicia en ≤ 10 s (prueba de aceptación 7).
